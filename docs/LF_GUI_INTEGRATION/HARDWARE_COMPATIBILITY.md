# 硬件兼容性

## 1. 当前设备

| 项目 | 值 |
|---|---|
| 设备 | Proxmark3（COM14，`VID_9AC4&PID_4B8F`） |
| MCU | AT91SAM7S256 Rev D，**256 KB Flash** |
| 固件 | `Iceman/master/v4.23346-suspect`，**裁剪掉 LF 功能** |
| Client | 同版本 `proxmark3.exe` |

## 2. 本次功能与硬件的关系

“低频多协议解析”是**纯文本解析**：

- 不发送任何 Proxmark3 命令；
- 不依赖 LF 固件、天线或卡片；
- 输入来自用户粘贴、文本文件或 `RawCommand` 已有输出。

因此当前裁剪固件**不影响**解析页面的完整性；也无法用该设备验证真实 LF 读取。

## 3. 界面如何表现

| 情况 | 行为 |
|---|---|
| 粘贴 `lf search` 输出 | 正常解析并显示协议/字段 |
| 粘贴 `lf t55xx detect` 输出 | 只读页显示芯片、block0 与位域 |
| 文本含 `unknown command` / `not supported` / `no response` | 说明区提示“当前固件可能不含低频功能，文本解析仍可用” |
| 没有 LF 数据 | 不显示任何可执行的低频写入/模拟入口 |

## 4. 与原有低频页面的关系

原有 `低频功能` 子标签仍使用 `LF` 模块与原有命令（`lf search/read/sniff/tune`、`lf config`、波形导出）。在当前固件下这些命令会由 Client 返回“不支持”，页面按原有逻辑显示错误；本次未改变其任何行为。

## 5. 未验证

- 真实 LF 卡（EM4100/HID/AWID/Indala 等）的读取与字段一致性；
- `lf t55xx detect/info` 在支持 LF 的固件上的输出解析（当前仅有固定 fixtures）；
- 调谐、嗅探、波形在真实设备上的回归。

以上均需换用包含 LF 的固件/设备，本阶段**未刷写固件**。

## 6. 结论

> 解析器支持 ≠ 设备支持。当前设备不具备 LF 能力，本页面仅证明文本解析与界面流程可用，不代表真实 LF 读取已验证。
