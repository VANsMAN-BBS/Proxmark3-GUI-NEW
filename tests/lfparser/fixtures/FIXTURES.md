# Test fixture provenance

Every fixture in this directory is a synthetic text produced for the parser
tests. None of them is a raw device capture; they follow the output layout of
the Proxmark3 client (`RfidResearchGroup/proxmark3`) and, where noted, reuse
values that appeared in the LF-Audit reference material.

| File | Protocol | Source of layout | Source of values | Real device log |
|---|---|---|---|---|
| `em4100_standard.txt` | EM4100 | `client/src/cmdlfem410x.c` (`EM 410x ID %010X`, `DEZ` block, `Pattern CDVI`) | Synthetic ID `0F00112233`; DEZ values were computed once and then hard-coded | No |
| `em4100_descramble_only.txt` | EM4100 | `cmdlfem410x.c` de-scramble section without the primary ID line | Synthetic | No |
| `hid_h10301.txt` | HID Prox | `client/src/wiegand_formats.c` `hid_print_card()` + `cmdlfhid.c` (`raw:`) | FC/CN/raw values taken from the LF-Audit historical sample (v4.20728) | No |
| `hid_multi_identical.txt` | HID Prox | same, two matching formats | Synthetic duplicate interpretation | No |
| `hid_conflict.txt` | HID Prox | same, conflicting formats | Synthetic conflict to test ambiguity handling | No |
| `hid_37bit.txt` | HID Prox 37-bit | same | Synthetic | No |
| `hid_corp1000.txt` | HID Corporate 1000 | same | Synthetic | No |
| `hid_unknown_format.txt` | HID Prox | bare `FC:/CN:` line without a Wiegand format name | Synthetic | No |
| `awid_26.txt` | AWID 26-bit | `client/src/cmdlfawid.c` `awid_decode_bits()` | Synthetic, modelled on the audit sample | No |
| `awid_50.txt` | AWID 50-bit | same, plus the `RBH - CN:` extra line | Synthetic | No |
| `indala_64_raw.txt` | Indala 64-bit | `client/src/cmdlfindala.c` `indala_print_decoded()` | Synthetic | No |
| `indala_64_no_raw.txt` | Indala 64-bit | same, raw line omitted on purpose | Synthetic | No |
| `no_card.txt` | none | `lf search` no-card trailer | Synthetic | No |
| `firmware_unsupported.txt` | none | real client message for a firmware without LF | Observed message text from the LF-Audit | No |
| `mixed_protocols.txt` | EM4100 + HID | concatenation used to verify dispatch priority | Synthetic | No |

## Rules

1. A fixture may only be marked as a real capture when it was produced by a
   device; none currently are.
2. When a real capture becomes available it must be added under a new name and
   this table updated with device, firmware and client versions.
3. Fixtures are plain `.txt` (UTF-8, no BOM) so that both LF and CRLF variants
   can be generated by the tests.
